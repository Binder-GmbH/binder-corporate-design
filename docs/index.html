The triad

Black, white and BINDER Red produce the primary BINDER colour impression. This triad is the core of the appearance and a design element in its own right. Everything else supports it and must never dilute its contrast.

How the three are used

ColourRole
WhiteUsed generously and over large areas: structure, backgrounds, white space, negative applications. White is what gives the triad its contrast.
BlackPrimary text colour, base for graphics and icons. Avoid large, full-coverage black areas.
BINDER RedThe highlight: emphasis in type, graphic elements, icons, anything that has to stand out.

Hex is for screen, CMYK is for print — do not convert between them. The grays carry a slight blue cast on screen but print as pure K with no CMY component. That is deliberate: converted exactly, the cast comes to under 6 % cyan, and cyan values that low cannot be reproduced reliably in offset printing.
White and black carry no number. They sit outside the ramp, exactly as $white and $black do in Bootstrap and Tailwind. A 0 would read as #000 — which is black.

Typography

The corporate typeface is Source Sans 3, designed by Paul D. Hunt. It is open source and free to use — no licence has to be purchased. Get it from Google Fonts, Adobe Fonts or GitHub. The specimen below is set in it.

Weights in use: Light 300, Regular 400, Medium 500, SemiBold 600.

Rules

  • Primary text colour is 100 % black. BINDER Red for emphasis, grays to de-emphasise. White on red or dark backgrounds.
  • Minimum size 6 pt — including text inside charts and diagrams.
  • Kerning: optical.
  • Old-style figures in body copy, lining figures in headlines, tabular figures in tables.

Body copy carries the argument. Structure the content before you set it: every topic needs exactly one clearly most important headline, and levels may be skipped where they are not needed. Content of equal weight gets headlines of equal weight.
Captions are set only where they add something the image does not already say.
Open question: the serif companion. The manual still describes a serif face for emotional text such as quotations, but names Source Sans 3 for it — which is a sans-serif. The same applies to the note on very large font sizes. These read as leftovers from replacing the previous typeface throughout the document. Ask the marketing department if you need a serif face for a quotation.

The red line above titles

A short horizontal red line sits directly above main titles — a discreet, distinctive element that ties visual communication together. All three measurements derive from the font size, so the rule holds at any scale.

PropertyRule
ColourBINDER Red
PlacementDirectly above the title, always flush left
Thickness0.10 × font size
LengthWidth of the first three letters of the title
Distance to title0.3 × font size

At 50 pt type: thickness 5 pt, distance 16.6 pt. At 25 pt type: thickness 2.5 pt, distance 8.3 pt.

The files carry different colour values than this corporate design. They contain #ed1c24 for red and #231f20 for black, while the CD specifies #e60000 and #000000. Both differences are visible and come from CMYK-to-RGB conversion in the print workflow. For screen work, set the colours from the palette above rather than trusting the values inside the files.

Clear space and position

The measure is X, the height of the Bildmarke. Keep 1.5 × X clear on all sides — no element may sit inside that zone. Place the logo top right, 2 × X from the format edge. The positioning distance is not the clear space; observe both.

Never

  • Use the word mark without the Bildmarke
  • Replace the typeface
  • Crop, compress, distort or rotate it
  • Add further elements to it
  • Recolour it beyond black, white or full colour
  • Use the Bildmarke as a bullet, watermark or decoration
