# BINDER Corporate Design

The corporate design of BINDER GmbH: logo, colors, typography and the rules for
applying them. This repository is the single source of truth for those assets —
so that websites, print material, presentations and partner communication all
draw from the same place.

## Status

Initial setup. Assets and guidelines are being added.

## Structure

```
logo/          Logo files (SVG, PNG) in the approved variants
colors/        Color definitions (HEX, RGB, CMYK, Pantone) and tokens
typography/    Fonts and type scale
templates/     Document, presentation and print templates
guidelines/    Written rules for correct usage
```

## Usage and rights

The BINDER name, logo and word/figurative marks are protected trademarks of
BINDER GmbH. Publishing these files makes them accessible for legitimate use —
press, partners, suppliers and integrators representing BINDER products — it
does not transfer any rights in the marks themselves. Modifying the logo,
recoloring it or using it in a way that suggests an endorsement or partnership
that does not exist is not permitted.

Questions about a specific use case: please open an issue or contact the
marketing department.
