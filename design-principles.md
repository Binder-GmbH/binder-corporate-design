# Design principles

## The triad

**Black, white and BINDER Red** produce the primary BINDER color impression.
Everything else supports it and must never dilute its contrast.

- **White** — used generously and over large areas: structure, backgrounds,
  white space, negative applications. White gives the triad its contrast.
- **Black** — primary text color, base for graphics and icons. Avoid large,
  full-coverage black areas.
- **BINDER Red** — the highlight: emphasis in type, graphic elements, icons.

## Formal language

| Do | Don't |
|---|---|
| Horizontal and vertical forms | Organic shapes |
| Circular elements as accents | Large diagonal areas or lines |
| Plenty of white space | Decorative elements |
| Clear information hierarchy | Unusual styling |
| Fact-driven, to the point | — |

For product information: tables, charts, diagrams, lists, short precise text,
product photography. For corporate and service content: authentic imagery,
light coloring, quotation layers.

## The red line above titles

A short red line sits directly above main titles. All measurements derive from
the font size, so the rule holds at any scale.

| Property | Rule |
|---|---|
| Color | BINDER Red |
| Placement | Directly above the title, always flush left |
| Thickness | **0.10 ×** font size |
| Length | Width of the **first three letters** of the title |
| Distance to title | **0.3 ×** font size |

At 50 pt type: thickness 5 pt, distance 16.6 pt.
